# Hardware scope

The article's core results use:

- **NVIDIA GeForce RTX 5090, 32 GB** for local llama.cpp/SGLang/DSPARK/Mia serving experiments.
- **Three NVIDIA DGX Spark systems** for the matched BF16 / FP8 / NVFP4 quality board.

Node nicknames, private network topology, local filesystem paths and fleet-control details are intentionally omitted because they do not improve reproducibility of the scientific claims.
